# Full Send Racing website

Official independent creator site for Fortnite island **0400-9013-9315** by Dawman89. The site targets relevant Rocket Racing and Fortnite racing searches without claiming to be Epic's official Rocket Racing.

## Publish for free
1. Make this repository **public** (GitHub Settings → General → Danger Zone → Change repository visibility). Do not change visibility unless you intend the site and code to be public.
2. Open repository Settings → Pages. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
3. Visit https://uefn-racer.github.io/full-send-racing/ after deployment completes.
4. In Google Search Console, verify ownership of the URL-prefix property `https://uefn-racer.github.io/full-send-racing/` and submit `https://uefn-racer.github.io/full-send-racing/sitemap.xml`.
5. Add authentic gameplay screenshots and confirm track names before promotion.
